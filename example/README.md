# FitPulse 示例

`unified_popups` 的产品化示例，包含四个业务页面和一个边界回归实验室。

## 运行

```bash
cd example
flutter pub get
flutter run
```

## 页面覆盖范围

| 区域 | 覆盖能力 |
| --- | --- |
| 今日 | Toast、Loading、Confirm |
| 训练 | Sheet 边缘停靠、Menu Anchor、训练 FlowSheet |
| 数据 | Date、导出 Loading |
| 我的 | 资料 Sheet、健康档案 FlowSheet、设置路由 |
| 实验室 | 无 context 异步调用、Handle 外部关闭、堆叠、返回键、路由变化 |

包文档见 [文档中心](../docs/README.md)。
